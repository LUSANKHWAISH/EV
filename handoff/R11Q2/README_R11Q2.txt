E.V. R11Q.2 — EV CRYSTAL CORE

SOURCE IDEA
-----------
This is a native QML translation of the supplied browser "Aether Core" concept.

The browser name has NOT been retained.
Inside E.V. this design is called:

EV CORE

WHAT WAS TRANSLATED
-------------------
- obsidian / black-glass crystal shell
- sapphire inner intelligence energy
- warm gold filament lattice
- internal 3D energy particles
- breathing idle
- shell expansion while listening
- particle attraction toward centre while listening
- faster inner rotation while planning
- speech-driven shell wave and gold response
- subtle state-dependent colour language

WHAT WAS NOT COPIED
-------------------
- Three.js
- WebGL browser runtime
- SpeechRecognition browser API
- browser buttons
- browser transcript UI
- Aether branding

WHY
---
E.V. already has its own:
- PySide6/QML application
- state bus
- GUI bridge
- state display
- future voice pipeline

So only the useful visual/animation language was translated.

R11Q.2 intentionally keeps the elegant background aura/ripple feel from R11Q.
It does NOT reuse the rejected R11Q.1 front/mid/rear mechanical planes.
